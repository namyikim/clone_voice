# clone_voice

가족의 목소리를 한 번 등록해 두면, 이후에는 문장만 입력해서 그 목소리로 음성을 만듭니다.
Google Colab에서 실행하고, 목소리와 결과물은 Google Drive에 보관합니다.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/namyikim/clone_voice/blob/main/clone_voice.ipynb)

## 어떻게 쓰나요

1. 위 배지를 눌러 Colab에서 노트북을 엽니다
2. **런타임 → 런타임 유형 변경 → GPU** 로 설정합니다
3. 셀 4개를 위에서부터 순서대로 실행합니다
4. 마지막 셀 아래에 UI가 나타납니다

처음에는 모델을 내려받느라 몇 분 걸리고, 그다음부터는 빠릅니다.

### 목소리 등록

**목소리 등록** 탭에서 이름을 적고, 마이크로 녹음하거나 파일을 올린 뒤 **등록**을 누릅니다.

- 3초 이상, 10~20초 정도가 무난합니다
- 조용한 곳에서 한 사람만 말하는 구간이 좋습니다
- 대본은 비워 두면 Whisper가 자동으로 받아씁니다. 결과가 화면에 나오니 틀린 곳만 고쳐서 **대본만 다시 저장**을 누르면 됩니다

한 번 등록하면 Drive에 남으므로 다시 녹음할 필요가 없습니다.

### 음성 생성

**음성 생성** 탭에서 목소리를 고르고 문장을 입력한 뒤 **음성 생성**을 누릅니다.
결과는 바로 재생되고 Drive의 `output` 폴더에도 저장됩니다.

## 어떻게 동작하나요

보이스 클로닝에는 두 가지가 필요합니다.

- **참조 음성** — 복제할 목소리가 담긴 녹음
- **참조 대본** — 그 녹음에 실제로 들어 있는 문장

모델은 "이 목소리가 이 문장을 이렇게 읽었다"는 짝을 보고 새 문장을 같은 목소리로 읽습니다.
그래서 대본이 녹음과 다르면 품질이 눈에 띄게 떨어집니다.

```
녹음 또는 업로드 ──▶ 16kHz wav 변환 ──┬──────────────────────┐
                                      │                      │
                      대본 있음? ─예─▶ 참조 대본              ├──▶ 음성 합성 ──▶ 결과 wav
                          │             ▲                    │
                          └─아니오─▶ Whisper 받아쓰기 ────────┤
                                     (txt로 저장)            │
                                                             │
생성할 문장 ─────────────────────────────────────────────────┘
```

Whisper는 대본이 없을 때만 로드되므로, 대본을 직접 적으면 VRAM을 아낄 수 있습니다.

## 파일과 폴더

노트북은 Drive의 아래 위치를 씁니다. 다른 곳을 쓰려면 3번 셀의 `VOICE_DIR` / `OUTPUT_DIR`만 고치면 됩니다.

```
MyDrive/2026/clone_voice/
├── recored_voice/            # 등록한 목소리
│   ├── 엄마.wav              # 참조 음성 (UI에서 등록하면 자동 생성)
│   ├── 엄마.txt              # 참조 대본 (비워 두면 Whisper가 생성)
│   └── 엄마_16k.wav          # 변환 캐시 (자동 생성)
└── output/                   # 생성 결과
    └── 엄마_20260915_143000.wav
```

UI를 거치지 않고 파일을 직접 넣어도 됩니다. **같은 이름**으로 음성 파일과 `.txt`를 두면 목록에 나타나고, `.txt`가 없으면 생성할 때 자동으로 만들어집니다.

| 구분 | 지원 확장자 |
|---|---|
| 음성 | `.m4a` `.mp3` `.wav` `.webm` `.ogg` `.flac` |
| 영상 | `.mp4` `.mov` `.mkv` `.avi` (오디오 트랙만 추출) |

## 설정

3번 셀 상단에 모여 있습니다.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `VOICE_DIR` | `MyDrive/2026/clone_voice/recored_voice` | 목소리 저장 폴더 |
| `OUTPUT_DIR` | `MyDrive/2026/clone_voice/output` | 결과 저장 폴더 |
| `MODEL_ID` | `Qwen/Qwen3-TTS-12Hz-0.6B-Base` | TTS 모델. `1.7B-Base`로 바꾸면 품질↑ VRAM↑ |
| `STT_MODEL_ID` | `openai/whisper-large-v3-turbo` | 받아쓰기 모델. 느리면 `openai/whisper-small` |
| `STT_LANGUAGE` | `ko` | 받아쓰기 언어 |
| `MIN_DURATION` | `3.0` | 이보다 짧으면 경고 |

## 개인정보

이 노트북은 **외부에 공개되지 않습니다.**

- `share=False`로 실행되어 공개 주소가 생기지 않습니다. 노트북을 실행한 본인의 브라우저에서만 UI가 열립니다
- 올린 파일은 Colab 세션의 임시 폴더에 놓였다가, **등록 버튼을 눌러야** Drive에 저장됩니다
- 세션이 끝나면 임시 파일은 사라집니다

`share=True`로 바꾸면 링크를 아는 사람이 등록된 목소리를 쓸 수 있게 되므로, 그럴 때는 반드시 `auth=("아이디", "비밀번호")`를 함께 지정하세요.

가족이라도 목소리를 복제하기 전에 알리고 동의를 받는 것이 좋습니다.
생성한 음성을 본인 외의 사람에게 들려줄 때는 AI로 만든 것임을 밝히세요.

## 문제 해결

| 증상 | 조치 |
|---|---|
| UI가 셀 안에 안 보임 | `demo.launch()`에 `share=True, auth=("아이디","비밀번호")` 추가 |
| 마이크 버튼이 동작하지 않음 | 브라우저 마이크 권한 허용 |
| 목록에 새 파일이 안 보임 | 생성 탭의 **목록 새로고침** |
| 결과가 원본과 안 닮음 | 참조 대본이 녹음과 일치하는지 확인. 3초 미만이거나 잡음이 많으면 품질 저하 |
| 대본이 깨져 보임 | `.txt`를 UTF-8로 다시 저장 |
| 오디오 트랙이 없다는 오류 | 무음 영상. 소리가 나는 파일인지 확인 |
| CUDA out of memory | 런타임 재시작. `STT_MODEL_ID`를 `openai/whisper-small`로 |
| 생성이 매우 느림 | GPU 런타임이 아님. 런타임 유형 확인 |
